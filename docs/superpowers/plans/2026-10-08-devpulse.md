# DevPulse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal macOS menu-bar utility that shows RAM/disk health as `● 62% / ● 71%`, a compact popover with the top-5 processes and top-5 heaviest files or folders, and a cleaner window that kills/relaunches processes and permanently deletes large files.

**Architecture:** All logic lives in a local Swift package `DevPulseCore` with no UI, covered by Swift Testing. A thin AppKit+SwiftUI app (`DevPulseApp`, generated by XcodeGen) owns an `NSStatusItem` with an attributed title, an `NSPopover` and an `NSWindow`, both hosting SwiftUI, and `@Observable @MainActor` stores that call into Core.

**Tech Stack:** Swift 6.3 (language mode 6), SwiftUI + AppKit, macOS 26, Swift Testing, XcodeGen 2.46, libproc / Mach host APIs, Foundation `FileManager`.

**Spec:** `docs/superpowers/specs/2026-10-08-devpulse-design.md`

## Global Constraints

- macOS deployment target `26.0`, Apple Silicon. Swift language mode 6, strict concurrency.
- No App Sandbox. Signing: Manual, identity `Apple Development: peppperrroni@gmail.com (5YY272N32R)`, team `ZGPM9P8T4A` (keeps TCC/Full Disk Access grants stable across rebuilds).
- `LSUIElement = YES` (no Dock icon). Bundle id `com.peppperrroni.devpulse`.
- UI copy is Russian, exactly as written in this plan.
- Sizes are decimal: `1 GB = 1_000_000_000` bytes. Display: `≥ 1 GB` → `"%.1f ГБ"`, otherwise `"%.0f МБ"`.
- Health colours: good `#4caf50`, warn `#ffb347`, bad `#b3261e`. Tokens: bg `#f2f1ee`/`#101014`, raised `#faf9f7`/`#1a1a20`, sunken `#e9e8e4`/`#0a0a0d`, ink `#101014`/`#f2f1ee`, mute `#6b6a66`/`#8d8c88`, accent `#2d81ff`, danger `#b3261e`.
- Thresholds: disk bad `< 10 GB` free; warn `< 30 GB` or `< 20 %` free; RAM colour from pressure level (sysctl 1 normal, 2 warn, 4 critical).
- Scan: whole `~`, keep nodes `≥ 50 MB`, default interval 6 h, top list 50 in the window and 5 in the popover.
- Protected roots (relative to `~`): `""`, `Library`, `Documents`, `Desktop`, `Downloads`, `Pictures`, `Movies`, `Music`, `Applications`, `Library/Containers`, `Library/Group Containers`, `Library/Mobile Documents`.
- Deletion is permanent (`FileManager.removeItem`), only after `Deleter.validate`.
- Terminate: SIGTERM (or `NSRunningApplication.terminate()`), offer SIGKILL after 3 s, never automatically. Relaunch waits ≤ 10 s. Pids `< 100` and DevPulse's own pid are not actionable.
- Fonts bundled: Inter, Geist Mono (OFL, both have Cyrillic). Display = SF heavy expanded, serif accents = New York italic (Archivo and Instrument Serif have no Cyrillic — verified with CoreText).

## Deviations from the spec (decided during planning, spec updated in Task 9)

1. **Status item is `NSStatusItem` + `NSPopover`, not `MenuBarExtra`.** A `MenuBarExtra` label supports one image plus one text and renders images monochrome, and a pre-rendered image cannot know the menu bar's wallpaper-dependent text colour on macOS 26. An attributed title gives coloured `●` runs and adaptive label-coloured text.
2. **Fonts:** Archivo → SF heavy expanded; Instrument Serif → New York italic (no Cyrillic glyphs).
3. **Java processes** are named by their main class (`GradleDaemon`, `KotlinCompileDaemon`) read from `KERN_PROCARGS2`. Four rows reading `java` cannot be told apart.

## Review Focus

1. **Deleting a huge folder (38 GB DerivedData) must not beachball the UI.** Deletion runs off the main actor, and the UI shows "Удаляю…". Pinned by: Task 12 runs `Deleter.delete` in `Task.detached`, and Task 7 tests `delete` on a background task.
2. **A cached tree whose dominant child was deleted must re-rank its parent.** After `applyDeletion`, `largestChildFolder` is recomputed. Pinned by: Task 8, `deletionRecomputesLargestChild`.
3. **Packages must never be ranked by their insides.** A 12 GB `.app` is one file; `Contents/` is never a folder candidate. Pinned by: Task 5, `packageIsOneItem`.
4. **A process that exits between listing and action reports "уже завершён", not a crash or a silent no-op.** Pinned by: Task 4, `signalOnExitedProcessThrowsNoSuchProcess`.
5. **Relative and `..` paths cannot escape validation.** `~/Library/Developer/../..` resolves to a protected root. Pinned by: Task 7, `dotDotTraversalIsRefused`.

```swift
public enum Health: Int, Comparable, Sendable {
    case good, warn, bad

    public static func < (lhs: Health, rhs: Health) -> Bool { lhs.rawValue < rhs.rawValue }
}

public enum MemoryPressure: Sendable, Equatable {
    case normal, warn, critical

    /// `kern.memorystatus_vm_pressure_level`: 1 normal, 2 warn, 4 critical.
    public init(sysctlLevel: Int32) {
        switch sysctlLevel {
        case 4...: self = .critical
        case 2...: self = .warn
        default: self = .normal
        }
    }
}

public enum HealthEvaluator {
    public static let gigabyte: Int64 = 1_000_000_000

    public static func ram(_ pressure: MemoryPressure) -> Health {
        switch pressure {
        case .normal: .good
        case .warn: .warn
        case .critical: .bad
        }
    }

    public static func disk(free: Int64, total: Int64) -> Health {
        if free < 10 * gigabyte { return .bad }
        if free < 30 * gigabyte || Double(free) < Double(total) * 0.2 { return .warn }
        return .good
    }
}
```

```swift
import Darwin
import Foundation

public struct SystemSnapshot: Sendable, Equatable {
    public var ramUsed: UInt64
    public var ramTotal: UInt64
    public var pressure: MemoryPressure
    public var diskFree: Int64
    public var diskTotal: Int64

    public init(ramUsed: UInt64, ramTotal: UInt64, pressure: MemoryPressure, diskFree: Int64, diskTotal: Int64) {
        self.ramUsed = ramUsed
        self.ramTotal = ramTotal
        self.pressure = pressure
        self.diskFree = diskFree
        self.diskTotal = diskTotal
    }

    public var ramPercent: Int { Self.percent(Double(ramUsed), of: Double(ramTotal)) }
    public var diskUsedPercent: Int { Self.percent(Double(diskTotal - diskFree), of: Double(diskTotal)) }
    public var ramHealth: Health { HealthEvaluator.ram(pressure) }
    public var diskHealth: Health { HealthEvaluator.disk(free: diskFree, total: diskTotal) }
    public var overall: Health { max(ramHealth, diskHealth) }

    private static func percent(_ part: Double, of whole: Double) -> Int {
        guard whole > 0 else { return 0 }
        return min(100, max(0, Int((part / whole * 100).rounded())))
    }
}

public enum SystemSampler {
    public static func sample() -> SystemSnapshot {
        let disk = diskCapacity()
        return SystemSnapshot(
            ramUsed: ramUsedBytes(),
            ramTotal: ProcessInfo.processInfo.physicalMemory,
            pressure: MemoryPressure(sysctlLevel: pressureLevel()),
            diskFree: disk.free,
            diskTotal: disk.total
        )
    }

    static func pressureLevel() -> Int32 {
        var level: Int32 = 0
        var size = MemoryLayout<Int32>.size
        guard sysctlbyname("kern.memorystatus_vm_pressure_level", &level, &size, nil, 0) == 0 else { return 1 }
        return level
    }

    /// Activity Monitor's "Memory Used": app memory (internal − purgeable) + wired + compressed.
    static func ramUsedBytes() -> UInt64 {
        var stats = vm_statistics64_data_t()
        var count = mach_msg_type_number_t(MemoryLayout<vm_statistics64_data_t>.stride / MemoryLayout<integer_t>.stride)
        let result = withUnsafeMutablePointer(to: &stats) {
            $0.withMemoryRebound(to: integer_t.self, capacity: Int(count)) {
                host_statistics64(mach_host_self(), HOST_VM_INFO64, $0, &count)
            }
        }
        guard result == KERN_SUCCESS else { return 0 }
        var pageSize: vm_size_t = 0
        host_page_size(mach_host_self(), &pageSize)
        let app = UInt64(stats.internal_page_count) - UInt64(min(stats.purgeable_count, stats.internal_page_count))
        let pages = app + UInt64(stats.wire_count) + UInt64(stats.compressor_page_count)
        return pages * UInt64(pageSize)
    }

    static func diskCapacity() -> (free: Int64, total: Int64) {
        let keys: Set<URLResourceKey> = [.volumeAvailableCapacityForImportantUsageKey, .volumeTotalCapacityKey]
        guard let values = try? URL(fileURLWithPath: "/").resourceValues(forKeys: keys) else { return (0, 0) }
        return (values.volumeAvailableCapacityForImportantUsage ?? 0, Int64(values.volumeTotalCapacity ?? 0))
    }
}
```

`Sources/DevPulseCore/ProcessSampler.swift`:
```swift
import Darwin
import Foundation

public struct ProcessEntry: Identifiable, Sendable, Equatable {
    public let pid: pid_t
    public var name: String
    public var path: String
    public var memory: UInt64
    public var cpuPercent: Double
    public var isApp: Bool

    public var id: pid_t { pid }
}

/// Lists the current user's processes. Holds the previous CPU times so the second
/// and later samples carry a CPU % (the first sample reports 0).
public final class ProcessSampler {
    private var previous: [pid_t: UInt64] = [:]   // pid → cpu ns
    private var previousAt: UInt64 = 0             // uptime ns
    private let timebase: (numer: UInt64, denom: UInt64)

    public init() {
        var info = mach_timebase_info_data_t()
        mach_timebase_info(&info)
        timebase = (UInt64(info.numer), UInt64(info.denom))
    }

    public func sample(apps: [pid_t: String]) -> [ProcessEntry] {
        let now = DispatchTime.now().uptimeNanoseconds
        let wall = previousAt == 0 ? 0 : now - previousAt
        var cpuNow: [pid_t: UInt64] = [:]
        var rows: [ProcessEntry] = []

        for pid in Self.userPIDs() {
            guard let usage = Self.rusage(pid) else { continue }
            // ri_user_time/ri_system_time are mach ticks on Apple Silicon.
            let cpu = (usage.ri_user_time + usage.ri_system_time) * timebase.numer / timebase.denom
            cpuNow[pid] = cpu
            var percent = 0.0
            if wall > 0, let before = previous[pid], cpu >= before {
                percent = Double(cpu - before) / Double(wall) * 100
            }
            let path = Self.path(pid)
            rows.append(ProcessEntry(
                pid: pid,
                name: apps[pid] ?? Self.displayName(pid: pid, path: path),
                path: path,
                memory: usage.ri_phys_footprint,
                cpuPercent: percent,
                isApp: apps[pid] != nil
            ))
        }
        previous = cpuNow
        previousAt = now
        return rows.sorted { $0.memory > $1.memory }
    }

    static func userPIDs() -> [pid_t] {
        let uid = UInt32(getuid())
        let needed = proc_listpids(UInt32(PROC_UID_ONLY), uid, nil, 0)
        guard needed > 0 else { return [] }
        var pids = [pid_t](repeating: 0, count: Int(needed) / MemoryLayout<pid_t>.size + 32)
        let bytes = proc_listpids(UInt32(PROC_UID_ONLY), uid, &pids, Int32(pids.count * MemoryLayout<pid_t>.size))
        guard bytes > 0 else { return [] }
        return pids.prefix(Int(bytes) / MemoryLayout<pid_t>.size).filter { $0 > 0 }
    }

    static func rusage(_ pid: pid_t) -> rusage_info_v4? {
        var info = rusage_info_v4()
        let result = withUnsafeMutablePointer(to: &info) {
            $0.withMemoryRebound(to: rusage_info_t?.self, capacity: 1) {
                proc_pid_rusage(pid, RUSAGE_INFO_V4, $0)
            }
        }
        return result == 0 ? info : nil
    }

    static func path(_ pid: pid_t) -> String {
        var buffer = [UInt8](repeating: 0, count: Int(MAXPATHLEN) * 4)
        let length = proc_pidpath(pid, &buffer, UInt32(buffer.count))
        guard length > 0 else { return "" }
        return String(decoding: buffer.prefix(Int(length)), as: UTF8.self)
    }

    static func displayName(pid: pid_t, path: String) -> String {
        let executable = path.isEmpty ? shortName(pid) : (path as NSString).lastPathComponent
        if executable == "java", let main = ProcessNaming.javaMainClass(arguments: ProcessNaming.arguments(pid: pid)) {
            return main
        }
        return executable
    }

    static func shortName(_ pid: pid_t) -> String {
        var buffer = [UInt8](repeating: 0, count: 256)
        let length = proc_name(pid, &buffer, UInt32(buffer.count))
        return length > 0 ? String(decoding: buffer.prefix(Int(length)), as: UTF8.self) : "pid \(pid)"
    }
}

public enum ProcessNaming {
    /// Main class (last segment) or jar file name of a `java` command line.
    public static func javaMainClass(arguments: [String]) -> String? {
        var index = 1
        while index < arguments.count {
            let arg = arguments[index]
            if arg == "-jar", index + 1 < arguments.count {
                return (arguments[index + 1] as NSString).lastPathComponent
            }
            if ["-cp", "-classpath", "--class-path", "-p", "--module-path"].contains(arg) {
                index += 2
                continue
            }
            if !arg.hasPrefix("-"), isQualifiedClassName(arg) {
                return String(arg.split(separator: ".").last!)
            }
            index += 1
        }
        return nil
    }

    private static func isQualifiedClassName(_ s: String) -> Bool {
        let parts = s.split(separator: ".", omittingEmptySubsequences: false)
        guard parts.count >= 2, let last = parts.last, last.first?.isUppercase == true else { return false }
        return parts.allSatisfy { part in
            guard let first = part.first, first.isLetter || first == "_" else { return false }
            return part.allSatisfy { $0.isLetter || $0.isNumber || $0 == "_" || $0 == "$" }
        }
    }

    /// argv of a process via KERN_PROCARGS2; empty when not readable.
    public static func arguments(pid: pid_t) -> [String] {
        var mib: [Int32] = [CTL_KERN, KERN_PROCARGS2, pid]
        var size = 0
        guard sysctl(&mib, 3, nil, &size, nil, 0) == 0, size > MemoryLayout<Int32>.size else { return [] }
        var buffer = [UInt8](repeating: 0, count: size)
        guard sysctl(&mib, 3, &buffer, &size, nil, 0) == 0 else { return [] }
        let argc = buffer.withUnsafeBytes { $0.loadUnaligned(as: Int32.self) }
        var i = MemoryLayout<Int32>.size
        while i < size, buffer[i] != 0 { i += 1 }   // executable path
        while i < size, buffer[i] == 0 { i += 1 }   // padding
        var args: [String] = []
        while args.count < Int(argc), i < size {
            let start = i
            while i < size, buffer[i] != 0 { i += 1 }
```

```swift
import AppKit
import Darwin

public enum KillError: Error, Equatable, Sendable {
    case notPermitted, noSuchProcess, other(Int32)
}

public enum RelaunchError: Error, Equatable, Sendable {
    case notAnApp, didNotExit, launchFailed(String)
}

public enum ProcessActions {
    public static func isActionable(_ pid: pid_t) -> Bool {
        pid >= 100 && pid != getpid()
    }

    /// True while the pid exists, including processes we may not signal.
    public static func isAlive(_ pid: pid_t) -> Bool {
        kill(pid, 0) == 0 || errno == EPERM
    }

    public static func signal(_ pid: pid_t, _ sig: Int32) throws(KillError) {
        guard kill(pid, sig) != 0 else { return }
        switch errno {
        case EPERM: throw .notPermitted
        case ESRCH: throw .noSuchProcess
        case let code: throw .other(code)
        }
    }

    /// Polite quit: Apple-event quit for GUI apps (lets them save), SIGTERM otherwise.
    @MainActor
    public static func terminate(_ pid: pid_t) throws(KillError) {
        if let app = NSRunningApplication(processIdentifier: pid), app.activationPolicy == .regular, app.terminate() {
            return
        }
        try signal(pid, SIGTERM)
    }

    public static func forceKill(_ pid: pid_t) throws(KillError) {
        try signal(pid, SIGKILL)
    }

    /// Quit a GUI app, wait for it to exit, launch it again. Never force-kills.
    @MainActor
    public static func relaunch(_ pid: pid_t, timeout: Duration = .seconds(10)) async throws(RelaunchError) {
        guard let app = NSRunningApplication(processIdentifier: pid),
              app.activationPolicy == .regular,
              let url = app.bundleURL else { throw .notAnApp }
        app.terminate()
        let clock = ContinuousClock()
        let deadline = clock.now + timeout
        while isAlive(pid) {
            if clock.now >= deadline { throw .didNotExit }
            try? await Task.sleep(for: .milliseconds(200))
        }
        do {
            _ = try await NSWorkspace.shared.openApplication(at: url, configuration: NSWorkspace.OpenConfiguration())
        } catch {
            throw .launchFailed(error.localizedDescription)
        }
    }
}
```

```swift
import Darwin
import Foundation

public struct DiskScanner: Sendable {
    public let keepThreshold: Int64

    public init(keepThreshold: Int64 = 50_000_000) {
        self.keepThreshold = keepThreshold
    }

    private static let keys: [URLResourceKey] = [
        .isDirectoryKey, .isPackageKey, .isSymbolicLinkKey, .totalFileAllocatedSizeKey,
        .fileAllocatedSizeKey, .contentModificationDateKey, .linkCountKey,
    ]

    private final class State {
        var bytes: Int64 = 0
        var items = 0
        var skipped: [String] = []
        var seenInodes = Set<UInt64>()
        let progress: @Sendable (ScanProgress) -> Void
        init(progress: @escaping @Sendable (ScanProgress) -> Void) { self.progress = progress }
    }

    public func scan(root: URL, progress: @escaping @Sendable (ScanProgress) -> Void = { _ in }) throws -> ScanResult {
        let state = State(progress: progress)
        let modified = try? root.resourceValues(forKeys: [.contentModificationDateKey]).contentModificationDate
        var node = try visit(root, kind: .folder, modified: modified, insidePackage: false, state: state)
        node.kind = .folder
        progress(ScanProgress(bytes: state.bytes, items: state.items))
        return ScanResult(date: Date(), root: node, skipped: state.skipped)
    }

    private func visit(_ url: URL, kind: NodeKind, modified: Date?, insidePackage: Bool, state: State) throws -> ScanNode {
        try Task.checkCancellation()
        let entries: [URL]
        do {
            entries = try FileManager.default.contentsOfDirectory(at: url, includingPropertiesForKeys: Self.keys)
        } catch {
            state.skipped.append(url.path)
            return ScanNode(path: url.path, size: 0, kind: kind, modified: modified, largestChildFolder: 0, children: [])
        }

        var size: Int64 = 0
        var largestFolder: Int64 = 0
        var kept: [ScanNode] = []
        for entry in entries {
            guard let v = try? entry.resourceValues(forKeys: Set(Self.keys)), v.isSymbolicLink != true else { continue }
            let child: ScanNode
            if v.isDirectory == true {
                let isPackage = !insidePackage && v.isPackage == true
                child = try visit(entry, kind: isPackage ? .package : .folder, modified: v.contentModificationDate,
                                  insidePackage: insidePackage || isPackage, state: state)
                if child.kind == .folder { largestFolder = max(largestFolder, child.size) }
            } else {
                child = ScanNode(path: entry.path, size: fileSize(entry, v, state), kind: .file,
                                 modified: v.contentModificationDate, largestChildFolder: 0, children: [])
            }
            size += child.size
            if !insidePackage, child.size >= keepThreshold { kept.append(child) }
        }

        if kind == .package { kept = []; largestFolder = 0 }
        kept.sort { $0.size > $1.size }
        return ScanNode(path: url.path, size: size, kind: kind, modified: modified,
                        largestChildFolder: largestFolder, children: kept)
    }

    private func fileSize(_ url: URL, _ v: URLResourceValues, _ state: State) -> Int64 {
        if (v.linkCount ?? 1) > 1 {
            var st = stat()
            if lstat(url.path, &st) == 0, !state.seenInodes.insert(UInt64(st.st_ino)).inserted { return 0 }
        }
        let size = Int64(v.totalFileAllocatedSize ?? v.fileAllocatedSize ?? 0)
        state.bytes += size
        state.items += 1
        if state.items % 5_000 == 0 { state.progress(ScanProgress(bytes: state.bytes, items: state.items)) }
        return size
    }
}
```

```swift
import Foundation

public struct TopItem: Identifiable, Hashable, Sendable {
    public var path: String
    public var size: Int64
    public var kind: NodeKind
    public var modified: Date?

    public var id: String { path }

    init(_ node: ScanNode) {
        path = node.path
        size = node.size
        kind = node.kind
        modified = node.modified
    }
}

public enum TopItems {
    public static func files(in root: ScanNode, limit: Int) -> [TopItem] {
        flatten(root).filter { $0.kind != .folder }
            .sorted { $0.size > $1.size }
            .prefix(limit).map(TopItem.init)
    }

    /// Folders where the weight actually sits: no child folder holds >= 50 % of the
    /// size, not a protected root, and no overlap with a larger chosen folder.
    public static func folders(in root: ScanNode, home: String, limit: Int) -> [TopItem] {
        let candidates = flatten(root)
            .filter { $0.kind == .folder && $0.size > 0 && $0.largestChildFolder * 2 < $0.size }
            .filter { !ProtectedPaths.isProtected($0.path, home: home) }
            .sorted { $0.size > $1.size }
        var chosen: [ScanNode] = []
        for node in candidates where chosen.count < limit {
            let overlaps = chosen.contains { $0.path.hasPrefix(node.path + "/") || node.path.hasPrefix($0.path + "/") }
            if !overlaps { chosen.append(node) }
        }
        return chosen.map(TopItem.init)
    }

    public static func all(in root: ScanNode, home: String, limit: Int) -> [TopItem] {
        (folders(in: root, home: home, limit: limit) + files(in: root, limit: limit))
            .sorted { $0.size > $1.size }
            .prefix(limit).map { $0 }
    }

    private static func flatten(_ node: ScanNode) -> [ScanNode] {
        [node] + node.children.flatMap(flatten)
    }
}
```

```swift
import Foundation

public enum DeleteRefusal: Error, Equatable, Sendable {
    case outsideHome, protected, missing
}

public struct DeletionReport: Sendable, Equatable {
    public struct Failure: Sendable, Equatable {
        public var path: String
        public var reason: String
    }

    public var freed: Int64 = 0
    public var deleted: [String] = []
    public var failures: [Failure] = []
}

/// Permanent deletion guarded by a path check that runs right before removal.
public struct Deleter: Sendable {
    public let home: String

    public init(home: String = NSHomeDirectory()) {
        self.home = Self.resolve(home)
    }

    /// Returns the resolved path that is safe to remove.
    public func validate(_ path: String) throws(DeleteRefusal) -> String {
        let resolved = Self.resolve(path)
        guard resolved.hasPrefix(home + "/") else { throw .outsideHome }
        guard !ProtectedPaths.isProtectedOrAncestor(resolved, home: home) else { throw .protected }
        guard FileManager.default.fileExists(atPath: resolved) else { throw .missing }
        return resolved
    }

    public func delete(_ items: [TopItem]) -> DeletionReport {
        var report = DeletionReport()
        for item in items {
            do {
                let path = try validate(item.path)
                try FileManager.default.removeItem(atPath: path)
                report.freed += item.size
                report.deleted.append(item.path)
            } catch let refusal as DeleteRefusal {
                report.failures.append(.init(path: item.path, reason: Self.describe(refusal)))
            } catch {
                report.failures.append(.init(path: item.path, reason: error.localizedDescription))
            }
        }
        return report
    }

    static func resolve(_ path: String) -> String {
        URL(fileURLWithPath: path).standardizedFileURL.resolvingSymlinksInPath().path
    }

    static func describe(_ refusal: DeleteRefusal) -> String {
        switch refusal {
        case .outsideHome: "вне домашней папки"
        case .protected: "защищённая папка"
        case .missing: "уже не существует"
        }
    }
}
```

```swift
import Foundation

public struct ScanCache: Sendable {
    public let url: URL

    public static var defaultURL: URL {
        FileManager.default.urls(for: .cachesDirectory, in: .userDomainMask)[0]
            .appending(path: "DevPulse/scan.json")
    }

    public init(url: URL) {
        self.url = url
    }

    /// nil when missing; a corrupt or outdated file is deleted so the caller rescans.
    public func load() -> ScanResult? {
        guard let data = try? Data(contentsOf: url) else { return nil }
        guard let result = try? JSONDecoder().decode(ScanResult.self, from: data),
              result.version == ScanResult.schemaVersion else {
            try? FileManager.default.removeItem(at: url)
            return nil
        }
        return result
    }

    public func save(_ result: ScanResult) throws {
        try FileManager.default.createDirectory(at: url.deletingLastPathComponent(), withIntermediateDirectories: true)
        try JSONEncoder().encode(result).write(to: url, options: .atomic)
    }
}

extension ScanResult {
    /// Removes the node at `path` and subtracts its size from every ancestor.
    public mutating func applyDeletion(of path: String) {
        _ = Self.remove(path, from: &root)
    }

    private static func remove(_ path: String, from node: inout ScanNode) -> Int64? {
        if let i = node.children.firstIndex(where: { $0.path == path }) {
            let removed = node.children.remove(at: i).size
            node.size -= removed
            node.largestChildFolder = largestFolder(in: node)
            return removed
        }
        guard let i = node.children.firstIndex(where: { path.hasPrefix($0.path + "/") }),
              let removed = remove(path, from: &node.children[i]) else { return nil }
        node.size -= removed
        node.largestChildFolder = largestFolder(in: node)
        node.children.sort { $0.size > $1.size }
        return removed
    }

    /// Approximation after an edit: only kept (>= threshold) children are known.
    private static func largestFolder(in node: ScanNode) -> Int64 {
        node.children.filter { $0.kind == .folder }.map(\.size).max() ?? 0
    }
}
```

```swift
enum Theme {
    static let bg = adaptive(0xF2F1EE, 0x101014)
    static let raised = adaptive(0xFAF9F7, 0x1A1A20)
    static let sunken = adaptive(0xE9E8E4, 0x0A0A0D)
    static let ink = adaptive(0x101014, 0xF2F1EE)
    static let mute = adaptive(0x6B6A66, 0x8D8C88)
    static let accent = Color(nsColor: NSColor(hex: 0x2D81FF))
    static let danger = Color(nsColor: NSColor(hex: 0xB3261E))

    static func nsColor(_ health: Health) -> NSColor {
        switch health {
        case .good: NSColor(hex: 0x4CAF50)
        case .warn: NSColor(hex: 0xFFB347)
        case .bad: NSColor(hex: 0xB3261E)
        }
    }

    static func color(_ health: Health) -> Color { Color(nsColor: nsColor(health)) }

    private static func adaptive(_ light: UInt32, _ dark: UInt32) -> Color {
        Color(nsColor: NSColor(name: nil) { appearance in
            appearance.bestMatch(from: [.darkAqua, .aqua]) == .darkAqua ? NSColor(hex: dark) : NSColor(hex: light)
        })
    }
}

extension NSColor {
    convenience init(hex: UInt32) {
        self.init(srgbRed: CGFloat((hex >> 16) & 0xFF) / 255, green: CGFloat((hex >> 8) & 0xFF) / 255,
                  blue: CGFloat(hex & 0xFF) / 255, alpha: 1)
    }
}

enum Fonts {
    /// Inter and Geist Mono ship in the bundle; if registration fails SwiftUI falls back to SF.
    static func register() {
        for url in Bundle.main.urls(forResourcesWithExtension: "ttf", subdirectory: nil) ?? [] {
            CTFontManagerRegisterFontsForURL(url as CFURL, .process, nil)
        }
    }

    static func display(_ size: CGFloat) -> Font { .system(size: size, weight: .heavy).width(.expanded) }
    static func body(_ size: CGFloat, _ weight: Font.Weight = .regular) -> Font { .custom("Inter", size: size).weight(weight) }
    static func mono(_ size: CGFloat, _ weight: Font.Weight = .regular) -> Font { .custom("Geist Mono", size: size).weight(weight) }
    static func serif(_ size: CGFloat) -> Font { .system(size: size, design: .serif).italic() }
}

enum Fmt {
    static func bytes(_ value: Int64) -> String {
        let gb = Double(value) / 1_000_000_000
        return gb >= 1 ? String(format: "%.1f ГБ", gb) : String(format: "%.0f МБ", Double(value) / 1_000_000)
    }

    static func bytes(_ value: UInt64) -> String { bytes(Int64(clamping: value)) }

    static func ago(_ date: Date) -> String {
        let minutes = Int(Date().timeIntervalSince(date) / 60)
        if minutes < 1 { return "только что" }
        if minutes < 60 { return "\(minutes) мин назад" }
        if minutes < 60 * 24 { return "\(minutes / 60) ч назад" }
        return "\(minutes / 60 / 24) дн назад"
    }

    static func modified(_ date: Date?) -> String {
        guard let date else { return "—" }
        let days = Int(Date().timeIntervalSince(date) / 86_400)
        switch days {
        case ..<1: return "сегодня"
        case 1: return "вчера"
        case 2..<14: return "\(days) дн"
        case 14..<60: return "\(days / 7) нед"
        case 60..<730: return "\(days / 30) мес"
        default: return "\(days / 365) г"
        }
    }
```

```swift
import DevPulseCore
import Observation

@Observable @MainActor
final class SystemStore {
    private(set) var snapshot = SystemSampler.sample()
    @ObservationIgnored var onChange: ((SystemSnapshot) -> Void)?
    @ObservationIgnored private var loop: Task<Void, Never>?

    func start() {
        guard loop == nil else { return }
        loop = Task { [weak self] in
            while !Task.isCancelled {
                guard let self else { return }
                self.snapshot = SystemSampler.sample()
                self.onChange?(self.snapshot)
                try? await Task.sleep(for: .seconds(2))
            }
        }
    }
}
```

```swift
import AppKit
import DevPulseCore
import Observation

@Observable @MainActor
final class ProcessStore {
    private(set) var processes: [ProcessEntry] = []
    /// Inline per-row messages: "нет прав", "уже завершён", relaunch failures.
    private(set) var notes: [pid_t: String] = [:]
    /// Rows that ignored SIGTERM for 3 s and now offer SIGKILL.
    private(set) var forceKillOffered: Set<pid_t> = []

    @ObservationIgnored private let sampler = ProcessSampler()
    @ObservationIgnored private var clients = 0
    @ObservationIgnored private var loop: Task<Void, Never>?

    var top5: [ProcessEntry] { Array(processes.prefix(5)) }

    /// Sampling runs only while the popover or the window is visible.
    func attach() {
        clients += 1
        guard loop == nil else { return }
        loop = Task { [weak self] in
            while !Task.isCancelled {
                self?.refresh()
                try? await Task.sleep(for: .seconds(2))
            }
        }
    }

    func detach() {
        clients = max(0, clients - 1)
        if clients == 0 {
            loop?.cancel()
            loop = nil
        }
    }

    func refresh() {
        var apps: [pid_t: String] = [:]
        for app in NSWorkspace.shared.runningApplications where app.activationPolicy == .regular {
            apps[app.processIdentifier] = app.localizedName ?? app.bundleURL?.deletingPathExtension().lastPathComponent
        }
        processes = sampler.sample(apps: apps)
        let alive = Set(processes.map(\.pid))
        forceKillOffered.formIntersection(alive)
    }

    func terminate(_ pids: Set<pid_t>) {
        for pid in pids where ProcessActions.isActionable(pid) {
            do {
                try ProcessActions.terminate(pid)
                notes[pid] = nil
                Task { [weak self] in
                    try? await Task.sleep(for: .seconds(3))
                    if ProcessActions.isAlive(pid) { self?.forceKillOffered.insert(pid) }
                    self?.refresh()
                }
            } catch {
                notes[pid] = Self.describe(error)
            }
        }
    }

    func forceKill(_ pid: pid_t) {
        do {
            try ProcessActions.forceKill(pid)
            forceKillOffered.remove(pid)
        } catch {
            notes[pid] = Self.describe(error)
        }
        refresh()
    }

    func relaunch(_ pid: pid_t) async {
        notes[pid] = "перезапуск…"
        do {
            try await ProcessActions.relaunch(pid)
            notes[pid] = nil
        } catch {
            notes[pid] = switch error {
            case .notAnApp: "не приложение"
            case .didNotExit: "не завершилось за 10 с — перезапуск отменён"
            case .launchFailed(let reason): "не запустилось: \(reason)"
            }
        }
        refresh()
    }

    private static func describe(_ error: KillError) -> String {
        switch error {
        case .notPermitted: "нет прав"
        case .noSuchProcess: "уже завершён"
        case .other(let code): "ошибка \(code)"
        }
    }
}
```

```swift
import DevPulseCore
import Foundation
import Observation

@Observable @MainActor
final class DiskStore {
    private(set) var result: ScanResult? { didSet { recomputeTop() } }
    /// Non-nil while a scan is running.
    private(set) var progress: ScanProgress?
    private(set) var isDeleting = false
    private(set) var lastReport: DeletionReport?
    private(set) var allTop: [TopItem] = []
    private(set) var filesTop: [TopItem] = []
    private(set) var foldersTop: [TopItem] = []

    var intervalHours: Int {
        didSet { UserDefaults.standard.set(intervalHours, forKey: "scanIntervalHours") }
    }

    @ObservationIgnored private let home = NSHomeDirectory()
    @ObservationIgnored private let cache = ScanCache(url: ScanCache.defaultURL)
    @ObservationIgnored private var scanTask: Task<ScanResult, Error>?
    @ObservationIgnored private var scheduler: Task<Void, Never>?

    init() {
        let saved = UserDefaults.standard.integer(forKey: "scanIntervalHours")
        intervalHours = saved > 0 ? saved : 6
        result = cache.load()
        recomputeTop()
    }

    var top5: [TopItem] { Array(allTop.prefix(5)) }

    var needsFullDiskAccess: Bool {
        (result?.skipped.filter { $0.hasPrefix(home + "/Library") }.count ?? 0) > 20
    }

    var isStale: Bool {
        guard let result else { return true }
        return Date().timeIntervalSince(result.date) > Double(intervalHours) * 3600
    }

    /// Checks every 5 minutes whether the cache is older than the interval.
    func start() {
        guard scheduler == nil else { return }
        scheduler = Task { [weak self] in
            while !Task.isCancelled {
                if let self, self.isStale, self.progress == nil { self.rescan() }
                try? await Task.sleep(for: .seconds(300))
            }
        }
    }

    func rescan() {
        guard progress == nil else { return }
        progress = ScanProgress(bytes: 0, items: 0)
        let root = URL(fileURLWithPath: home)
        // The store lives for the whole app run, so a strong capture is fine and
        // avoids a mutable weak capture inside a @Sendable closure.
        let store = self
        let task = Task.detached(priority: .utility) {
            try DiskScanner().scan(root: root) { p in
                Task { @MainActor in if store.progress != nil { store.progress = p } }
            }
        }
        scanTask = task
        Task {
            if let finished = try? await task.value {
                result = finished
                try? cache.save(finished)
            }
            progress = nil
            scanTask = nil
        }
    }

    /// Cancellation keeps the previous cache.
    func cancelScan() {
        scanTask?.cancel()
    }

    func delete(_ items: [TopItem]) async {
        isDeleting = true
        let home = home
        let report = await Task.detached(priority: .userInitiated) { Deleter(home: home).delete(items) }.value
        if var updated = result {
            for path in report.deleted { updated.applyDeletion(of: path) }
            result = updated
            try? cache.save(updated)
        }
        lastReport = report
        isDeleting = false
    }

    func dismissReport() {
        lastReport = nil
    }

    private func recomputeTop() {
        guard let root = result?.root else {
            allTop = []; filesTop = []; foldersTop = []
            return
        }
        allTop = TopItems.all(in: root, home: home, limit: 50)
        filesTop = TopItems.files(in: root, limit: 50)
        foldersTop = TopItems.folders(in: root, home: home, limit: 50)
    }
}
```

```swift
struct ProcessesTab<Tabs: View>: View {

        let filtered = filter.isEmpty ? store.processes
            : store.processes.filter { $0.name.localizedCaseInsensitiveContains(filter) || $0.path.localizedCaseInsensitiveContains(filter) }
        return filtered.sorted(using: sortOrder)
```

```swift
import AppKit
import DevPulseCore
import SwiftUI

struct FilesTab<Tabs: View>: View {
    enum Filter: Hashable { case all, files, folders }

    let tabs: Tabs
    @Environment(DiskStore.self) private var disk
    @Environment(SystemStore.self) private var system
    @Environment(Navigation.self) private var navigation
    @State private var filter: Filter = .all
    @State private var confirming: [TopItem] = []
    @State private var showSettings = false

    private var rows: [TopItem] {
        switch filter {
        case .all: disk.allTop
        case .files: disk.filesTop
        case .folders: disk.foldersTop
        }
    }

    private var selectedItems: [TopItem] {
        rows.filter { navigation.selectedPaths.contains($0.path) }
    }

    var body: some View {
        @Bindable var navigation = navigation
        VStack(alignment: .leading, spacing: 0) {
            header
            if disk.needsFullDiskAccess { fdaHint }
            HStack {
                Segmented(options: [(.all, "Все"), (.files, "Файлы"), (.folders, "Папки")], selection: $filter)
                    .frame(width: 240)
                Spacer()
                Button("Показать в Finder") {
                    NSWorkspace.shared.activateFileViewerSelecting(selectedItems.map { URL(fileURLWithPath: $0.path) })
                }
                .buttonStyle(DPButtonStyle())
                .disabled(selectedItems.isEmpty)
                Button(disk.isDeleting ? "Удаляю…" : "Удалить навсегда") { confirming = selectedItems }
                    .buttonStyle(DPButtonStyle(kind: .danger))
                    .disabled(selectedItems.isEmpty || disk.isDeleting)
            }
            .padding(16)

            Table(rows, selection: $navigation.selectedPaths) {
                TableColumn("Путь") { item in
                    HStack(spacing: 6) {
                        Image(systemName: item.kind == .folder ? "folder" : "doc").foregroundStyle(Theme.mute)
                        Text(abbreviate(item.path)).font(Fonts.body(12.5)).lineLimit(1).truncationMode(.middle)
                    }
                    .help(item.path)
                }
                TableColumn("Размер") { item in
                    Text(Fmt.bytes(item.size)).font(Fonts.mono(11.5, .medium)).frame(maxWidth: .infinity, alignment: .trailing)
                }
                .width(90)
                TableColumn("Изменён") { item in
                    Text(Fmt.modified(item.modified)).font(Fonts.mono(11.5)).foregroundStyle(Theme.mute)
                        .frame(maxWidth: .infinity, alignment: .trailing)
                }
                .width(80)
            }
            .scrollContentBackground(.hidden)
            .overlay {
                if rows.isEmpty {
                    Text(disk.progress == nil ? "Скан ещё не выполнен" : "Сканирую…")
                        .font(Fonts.body(13)).foregroundStyle(Theme.mute)
                }
            }
        }
        .sheet(isPresented: Binding(get: { !confirming.isEmpty }, set: { if !$0 { confirming = [] } })) {
            ConfirmDeleteSheet(items: confirming) {
                let items = confirming
                confirming = []
                navigation.selectedPaths = []
                Task { await disk.delete(items) }
            } cancel: {
                confirming = []
            }
        }
        .alert(reportTitle, isPresented: Binding(get: { disk.lastReport != nil }, set: { if !$0 { disk.dismissReport() } })) {
            Button("OK") { disk.dismissReport() }
        } message: {
            Text(reportMessage)
        }
    }

    private var header: some View {
        HStack(alignment: .center) {
            VStack(alignment: .leading, spacing: 2) {
                HStack(spacing: 6) {
                    SectionLabel(text: "02 / Файлы · \(scanLine)")
                    if disk.progress == nil {
                        Button { disk.rescan() } label: { Image(systemName: "arrow.clockwise") }
                            .buttonStyle(.plain).foregroundStyle(Theme.mute).help("Пересканировать")
                    } else {
                        Button { disk.cancelScan() } label: { Image(systemName: "xmark.circle") }
                            .buttonStyle(.plain).foregroundStyle(Theme.mute).help("Остановить скан")
                    }
                    Button { showSettings = true } label: { Image(systemName: "gearshape") }
                        .buttonStyle(.plain).foregroundStyle(Theme.mute)
                        .popover(isPresented: $showSettings) { settings }
                }
                HStack(alignment: .firstTextBaseline, spacing: 6) {
                    Text("\(Fmt.bytes(system.snapshot.diskFree)) свободно").font(Fonts.display(20)).foregroundStyle(Theme.ink)
                    Text("из \(Fmt.bytes(system.snapshot.diskTotal))").font(Fonts.serif(16)).foregroundStyle(Theme.mute)
                }
            }
            Spacer()
            tabs
        }
        .padding([.horizontal, .top], 16)
    }

    private var scanLine: String {
        if let p = disk.progress { return "сканирую · \(Fmt.bytes(p.bytes)) · \(p.items) файлов" }
        guard let date = disk.result?.date else { return "скан не выполнен" }
        return "скан \(Fmt.ago(date))"
    }

    private var fdaHint: some View {
        HStack {
            Text("Часть ~/Library недоступна — выдай DevPulse «Полный доступ к диску», чтобы скан видел всё.")
                .font(Fonts.body(12)).foregroundStyle(Theme.ink)
            Spacer()
            Button("Открыть настройки") {
                NSWorkspace.shared.open(URL(string: "x-apple.systempreferences:com.apple.preference.security?Privacy_AllFiles")!)
            }
            .buttonStyle(DPButtonStyle())
        }
        .padding(10)
        .background(RoundedRectangle(cornerRadius: 8).fill(Color(nsColor: NSColor(hex: 0xFFB347)).opacity(0.2)))
        .padding(.horizontal, 16)
        .padding(.top, 10)
    }

    private var settings: some View {
        @Bindable var disk = disk
        return VStack(alignment: .leading, spacing: 8) {
            SectionLabel(text: "Настройки")
            Stepper("Скан каждые \(disk.intervalHours) ч", value: $disk.intervalHours, in: 1...48)
                .font(Fonts.body(12.5))
        }
        .padding(14)
        .frame(width: 240)
    }

    private var reportTitle: String {
        guard let r = disk.lastReport else { return "" }
        return "Освобождено \(Fmt.bytes(r.freed))"
    }

    private var reportMessage: String {
        guard let r = disk.lastReport, !r.failures.isEmpty else { return "" }
        return "Не удалось:\n" + r.failures.map { "\(abbreviate($0.path)) — \($0.reason)" }.joined(separator: "\n")
    }
}

struct ConfirmDeleteSheet: View {
    let items: [TopItem]
    let confirm: () -> Void
    let cancel: () -> Void

    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            SectionLabel(text: "Удалить навсегда")
            Text(Fmt.bytes(items.reduce(0) { $0 + $1.size })).font(Fonts.display(22)).foregroundStyle(Theme.ink)
            ScrollView {
                VStack(alignment: .leading, spacing: 4) {
                    ForEach(items) { item in
                        HStack {
                            Text(abbreviate(item.path)).font(Fonts.mono(11.5)).lineLimit(1).truncationMode(.middle)
                            Spacer()
                            Text(Fmt.bytes(item.size)).font(Fonts.mono(11.5, .medium))
                        }
                    }
                }
            }
            .frame(maxHeight: 160)
            Text("Удаление необратимо — в Корзину не попадёт.").font(Fonts.body(12)).foregroundStyle(Theme.danger)
            HStack {
                Spacer()
                Button("Отмена", action: cancel).buttonStyle(DPButtonStyle()).keyboardShortcut(.cancelAction)
                Button("Удалить навсегда", action: confirm).buttonStyle(DPButtonStyle(kind: .danger))
            }
        }
        .padding(20)
        .frame(width: 440)
        .background(Theme.bg)
    }
}
```
